# insonic Web/React adapter

GENERATED by BrandBuilder. Use `../tokens/interface.css` without React. React consumers install exact `radix-ui@1.6.7` and import static components from `react/server`, environment synchronization without Radix from `react/environment`, and interactive components from `react/client`. The client entry re-exports the environment helpers for compatibility. AppFrame defaults to the contained layout; application shells may select the bounded `full-bleed` layout. Next.js and Vite use the same entry points. Tauri and Wails hosts must select their declared ownership profile and must not also consume AppFrame-owned insets. Tailwind may consume the custom properties but is not canonical.

The parent kit's `color-roles.json` records approved formal combinations, artwork references, interface cues, and measured pairings.
