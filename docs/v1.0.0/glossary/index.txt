15:Tdce1,<h1 id="glossary">Glossary</h1>
<p>This glossary defines the technical vocabulary used in the system contracts. Each entry links to a primary learning resource and the local pages where the term is used most heavily. External references explain the underlying technology; the linked insonic contracts define its application here.</p>

<td>Ad-hoc code signature</td>
<td>A code-integrity signature without a configured publisher identity. macOS ARM64 uses it for native loader integrity; it does not establish publisher signing or notarization.</td>
<td><a href="https://developer.apple.com/documentation/security/seccodesignatureflags/adhoc">Apple ad-hoc signature flag</a>; <a href="/docs/v1.0.0/releases/">Releases</a>, <a href="/docs/v1.0.0/desktop/">desktop</a></td>
</tr>

<td>CNAME (Pages file)</td>
<td>The repository file retaining the existing custom domain for the static documentation host. It is distinct from a DNS CNAME record, which aliases one DNS name to another.</td>
<td><a href="https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site">GitHub Pages custom domains</a>; <a href="/docs/v1.0.0/releases/">Releases</a></td>

<td>AES-GCM</td>

<td><a href="https://csrc.nist.gov/pubs/sp/800/38/d/final">NIST GCM specification</a>; <a href="/docs/v1.0.0/security/">Security</a>, <a href="/docs/v1.0.0/secrets/">credential commands</a></td>

<td>Argon2id / KDF</td>

</tr>

<td>CAS (compare-and-swap)</td>

<td><a href="https://www.sqlite.org/isolation.html">SQLite isolation</a>; <a href="/docs/v1.0.0/speakers/">Speakers</a>, <a href="/docs/v1.0.0/voice-models/">voice models</a></td>

<td>CUDA</td>

<td>RMS (root mean square)</td>

</tr>

<td>DNS (Domain Name System)</td>
