# Glossary

This glossary defines the technical vocabulary used in the system contracts. Each entry links to a primary learning resource and the local pages where the term is used most heavily. External references explain the underlying technology; the linked insonic contracts define its application here.

| Term | Meaning in insonic | Learn and local usage |
| --- | --- | --- |
| Adapter | A replaceable implementation of a declared capability, with versioned configuration, results and errors. | [Go interfaces](https://go.dev/tour/methods/9); [Pipelines](pipelines.md), [architecture](architecture.md) |
| Alias | A revisioned name for a catalog speaker, with scope and provenance; identical text does not automatically merge identities. | [W3C provenance model](https://www.w3.org/TR/prov-dm/); [Speakers](speakers.md), [schema](schema.md) |
| Model alias | A revisioned workspace convenience reference to one exact model target; retargeting affects future elections while historical jobs keep their selected identities. | [Revision-pinned downloads](https://huggingface.co/docs/huggingface_hub/main/guides/download); [Models](models.md), [pipelines](pipelines.md) |
| Model acquisition dependency | Durable verified bundle acquisition that must succeed before a dependent processing stage runs; multiple consumers can share it without occupying waiting worker slots. | [Content identity](https://csrc.nist.gov/pubs/fips/180-4/upd1/final); [Models](models.md), [pipelines](pipelines.md) |
| Alignment | Matching selected transcript text to audio to produce timed observations without silently replacing the text. | [PyTorch alignment tutorial](https://docs.pytorch.org/audio/stable/tutorials/forced_alignment_tutorial.html); [Pipelines](pipelines.md), [subtitles](subtitles.md) |
| API (application programming interface) | The requests, results and errors through which components invoke shared application behavior. | [OpenAPI concepts](https://spec.openapis.org/oas/latest.html); [Architecture](architecture.md), [desktop](desktop.md) |
| ArcadeDB | The supported server graph backend selected through its configured endpoint and database. | [ArcadeDB HTTP API](https://docs.arcadedb.com/arcadedb/reference/http-api/http); [Graph](graph.md), [technology](technology.md) |
| Artifact | An immutable byte object, such as original media, a metadata report, mapped audio or model weights, with digest and location records. | [W3C provenance model](https://www.w3.org/TR/prov-dm/); [Storage](storage.md), [schema](schema.md) |
| ASR (automatic speech recognition) | A model operation that turns spoken audio into text; useful correlated results also require timing. | [faster-whisper](https://github.com/SYSTRAN/faster-whisper); [Pipelines](pipelines.md), [technology](technology.md) |
| Assertion | A structured proposition attributed to cited source evidence, including its polarity and conditions; storage does not establish its truth. | [W3C statement model](https://www.w3.org/TR/rdf11-concepts/); [Graph](graph.md), [schema](schema.md) |
| Attribution | A revisioned observation linking a run-local voice or source interval to a speaker, with basis, confidence and provenance. | [W3C provenance model](https://www.w3.org/TR/prov-dm/); [Speakers](speakers.md), [voice models](voice-models.md) |
| Authenticated encryption | Encryption that also detects ciphertext modification, used by an encrypted credential vault through maintained libraries. | [Authenticated encryption standard](https://www.rfc-editor.org/rfc/rfc5116); [security](security.md) |
| Canonical audio | The durable standardized recording audio, with source provenance and independent track clocks; model preparation is disposable. | [FFmpeg formats](https://ffmpeg.org/ffmpeg-formats.html); [Media](media.md), [ingestion](ingestion.md) |
| FLAC | Lossless integer audio encoding used for stereo, larger channel layouts and grouped tracks. | [FLAC format](https://xiph.org/flac/format.html); [Media](media.md) |
| Matroska audio (.mka) | An audio-only container grouping independent tracks with language and timestamp metadata. | [Matroska specification](https://www.matroska.org/technical/elements.html); [Media](media.md), [desktop](desktop.md) |
| MP3 V0 | High-quality variable-bitrate MP3 encoding for eligible lossy mono sources, subject to the FLAC override. | [LAME documentation](https://lame.sourceforge.io/using.php); [Media](media.md) |
| Recording-local speaker token | An exact upstream-valid identifier scoped to one recording/document, distinct from a known-person UUID. | [Cueson consumer contract](https://github.com/shruggietech/cueson/blob/v1.2.0/docs/consumer-speakers.md); [Subtitles](subtitles.md), [speakers](speakers.md) |
| Catalog | The SQLite or PostgreSQL authority for operational state, associations, selections and user edits. | [SQLite transactions](https://www.sqlite.org/transactional.html); [Architecture](architecture.md), [schema](schema.md) |
| Cgo | Go's mechanism for calling C code, introducing native-library and platform packaging requirements. | [Cgo documentation](https://pkg.go.dev/cmd/cgo); [Technology](technology.md), [architecture](architecture.md) |
| Checkpoint (graph) | The last atomically committed projection event, generation and catalog revision used to reconcile publication and replay. | [Transactional outbox pattern](https://microservices.io/patterns/data/transactional-outbox.html); [Graph](graph.md), [architecture](architecture.md) |
| Checkpoint (model) | Persisted training state or weights that permit a compatible adapter to resume or recover a training attempt. | [PyTorch model persistence](https://docs.pytorch.org/tutorials/beginner/saving_loading_models.html); [Voice models](voice-models.md), [schema](schema.md) |
| Chunk | A bounded window of selected transcript cues prepared for an adapter, retaining exact cue and source interval references. | [faster-whisper](https://github.com/SYSTRAN/faster-whisper); [Graph](graph.md), [pipelines](pipelines.md) |
| CLI (command-line interface) | The text and automation interface exposing application operations, human output and versioned JSON results. | [Go documentation](https://go.dev/doc/); [Desktop](desktop.md), [architecture](architecture.md) |
| Codec | An encoding/decoding method for media streams whose exact implementation and licensing matter for packaging. | [ffprobe documentation](https://ffmpeg.org/ffprobe.html); [Media](media.md), [technology](technology.md) |
| Content-addressed storage | Managed object naming derived from a content digest, with separate logical IDs and physical locations. | [NIST Secure Hash Standard](https://csrc.nist.gov/pubs/fips/180-4/upd1/final); [Storage](storage.md), [media](media.md) |
| Corpus | Audio segments selected across the library by a speaker-linked policy; training freezes a particular membership snapshot. | [OpenLineage model](https://openlineage.io/docs/spec/object-model/); [Voice models](voice-models.md), [speakers](speakers.md) |
| Correlation | The recorded link between an artifact or observation and original media, including a mapping between their time coordinates. | [W3C provenance model](https://www.w3.org/TR/prov-dm/); [Media](media.md), [subtitles](subtitles.md) |
| CPU / GPU | A general-purpose processor and a graphics/compute accelerator; scheduling and model profiles account for their capacity separately. | [CTranslate2 hardware support](https://opennmt.net/CTranslate2/hardware_support.html); [technology](technology.md), [pipelines](pipelines.md) |
| CTranslate2 | The inference engine used by faster-whisper, with qualified hardware and numeric-format support. | [CTranslate2 documentation](https://opennmt.net/CTranslate2/); [technology](technology.md) |
| Cue | A timed subtitle unit carrying text and format-specific fields; cue boundaries need not equal acoustic speaker boundaries. | [WebVTT specification](https://www.w3.org/TR/webvtt1/); [Subtitles](subtitles.md), [graph](graph.md) |
| Cue JSON | Cueson's schema-governed subtitle document, including source bytes, common cues and native-format fields. | [Cueson schema](https://github.com/shruggietech/cueson/blob/v1.2.0/docs/schema.md); [Subtitles](subtitles.md), [contracts](contracts.md) |
| Cueson | The required upstream executable and schema that govern subtitle admission, normalization, validation and rendering. | [Cueson schema](https://github.com/shruggietech/cueson/blob/v1.2.0/docs/schema.md); [Subtitles](subtitles.md), [technology](technology.md) |
| Dataset snapshot | A bounded selection of current recording/document/cue references and source digests for training; replacement invalidates obsolete preparation instead of retaining copied assignments. | [OpenLineage model](https://openlineage.io/docs/spec/object-model/); [Voice models](voice-models.md), [schema](schema.md) |
| Derivative | An artifact produced from a parent by recorded transforms, preserving parent identity and time/channel mappings. | [W3C provenance model](https://www.w3.org/TR/prov-dm/); [Media](media.md), [pipelines](pipelines.md) |
| Diarization | Acoustic segmentation of which voice spoke when, including overlapping speech; it does not itself name a person. | [pyannote audio](https://github.com/pyannote/pyannote-audio); [Speakers](speakers.md), [technology](technology.md) |
| Digest / SHA-256 | A cryptographic hash of exact bytes used for content identity and integrity checks; it is separate from an object-store ETag. | [NIST Secure Hash Standard](https://csrc.nist.gov/pubs/fips/180-4/upd1/final); [Storage](storage.md), [media](media.md) |

| Embedding | A model-produced numeric vector for an explicitly scoped audio/text input, stored with model and source provenance. | [pyannote audio](https://github.com/pyannote/pyannote-audio); [Speakers](speakers.md), [pipelines](pipelines.md) |
| ETag | An object-store transport/version validator whose meaning depends on the provider and upload; it is not an insonic SHA-256 digest. | [S3 object metadata](https://docs.aws.amazon.com/AmazonS3/latest/userguide/UsingMetadata.html); [Storage](storage.md), [architecture](architecture.md) |
| Evidence span | The exact cue references and original-media intervals supporting a result or assertion. | [W3C provenance model](https://www.w3.org/TR/prov-dm/); [Graph](graph.md), [schema](schema.md) |
