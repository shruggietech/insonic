# Documentation

Start with the [documented system contracts](https://insonic.io/docs/latest/). The index identifies candidate and publication status. Browse source versions through the [version manifest](versions.json), which defines navigation and the current version.

Markdown under `docs/<version>/` is the documentation authority. The static Next.js renderer lives in `site/`; `site/out/` is the public website and `site/offline/` is the documentation-only bundle for the GUI. See [the publication contract](https://insonic.io/docs/latest/releases/) for synchronized versions and packaging. The site also renders the [master changelog](https://insonic.io/docs/latest/changelog/) and [JSON contracts](https://insonic.io/docs/latest/contracts/). The 0.0.0 specification baseline remains available.
