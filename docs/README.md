# Documentation

Start with the [v1.0.0 system contracts](v1.0.0/index.md). The index identifies candidate and publication status.

Markdown under `docs/<version>/` is the documentation authority. `versions.json` defines navigation and the default version. The static Next.js renderer lives in `site/`; `site/out/` is the public website and `site/offline/` is the documentation-only bundle for the GUI. See [the publication contract](v1.0.0/releases.md) for synchronized versions and packaging. The site also renders the [master changelog](v1.0.0/changelog.md) and [JSON contracts](v1.0.0/contracts.md). The 0.0.0 specification baseline remains available.
