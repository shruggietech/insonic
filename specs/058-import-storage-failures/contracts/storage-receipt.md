# Internal storage qualification receipt

Maintainer evidence, not a new public runtime schema.

The nested storage_contracts receipt must bind its format, Windows/Linux platform and exact executed image to a complete canonical-publication refusal/recovery case. Record source digest/size, accepted sentinel identity/digest, blocker identity/digest, failed and successful work identities and item outcomes, accepted canonical/report bindings, preserved metadata/date provenance, replay identity and verified runtime/blocker/path cleanup.

Origin is actual-filesystem-obstruction; physical capacity exhaustion is explicitly unexecuted. Native ENOSPC/short-write/report/persistence tests are injected and cannot substitute for this case. Missing/mismatched source/image/platform, absent failure, wrong admission count, changed sentinel/source, incomplete final authority, stale request reuse or incomplete cleanup fails validation.

Package archive/inventory authority remains inherited from coverage.identity and independently rechecked by release/CI audit. Modern/unknown receipts require this evidence, with existing exact original-release exemptions only.
