# Internal native diagnostic contract

Failure evidence contains kind=native-exit-child-failure, stage=native-exit, action, stdout, stderr, exit_code, truncated, timed_out and cancelled. Each stream is bounded to 65536 bytes. A controller error before readiness is startup failure, not proof of a failed native action.

Successful Exit JSON continues requiring native_exit/no_workspace_exit/workspace_exit/ordinary_close/playback_cleanup/runtime_work_survival and current schema version. Real Windows keyboard/menu and Linux menu routes remain required. No callback or forced-kill fallback may produce success.

The manual diagnostic requires an acknowledged disposable CI host and validated incident assets. It records tool/payload identities separately and emits no delivery authority. Old-byte direct children are labelled as differing from production-parent ownership.

A producer-failure observation remains bound to selected run/attempt/revision. Missing, failed, cancelled, skipped or foreign producers still reject immediately.
