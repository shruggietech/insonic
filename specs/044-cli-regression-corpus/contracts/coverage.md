# Maintainer coverage contract

Inventory validation is offline and deterministic. Unknown shape, duplicate IDs, invalid generator/assertion references, changed pinned manifest identity and escaping paths fail.

Installed authority comes from the current root/context help. Observation aggregation discards values before retention; unknown accepted command/option references fail. Parser/help outcomes cannot assert successful operations. Semantic success requires a named completed assertion, and expected failures retain their actual category/reason. Unexecuted capabilities stay unverified.

Each source/package CLI receipt includes a bounded coverage ledger. Executable and existing verified package inventory identities bind observations to the elected artifact; companion-dependent source-lane omissions remain explicit. CI is the retained execution evidence location; owned local scratch is removed.
