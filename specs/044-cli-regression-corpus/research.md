The installed-path campaign exposed capture failures before ledger execution; source and package checks continue to require successful captures, without an ASCII path restriction.

- Decision: distinguish invocation checks from asserted outcomes. Rationale: cli_help_examples.py currently labels some immediate non-null results succeeded and misses option coverage. Rejected: treating help or broad expected-code sets as semantic proof.
- Decision: index existing eight regression modules, documented trainer workflows and licensed media manifest. Rationale: their byte/timing/HTTP/credential checks already exist. Rejected: recreating old audit scratch inputs or adding a second journey.
- Decision: bind to CLI hash and existing verified package inventory; rename owned library/install roots for missing Unicode destination coverage. Rationale: extracted paths and media names already contain Unicode, while those destinations do not.
- Decision: assert joined provider/documented threads stop before claiming cleanup. Rationale: current joins omit the live-thread check present in media qualification.
- All implementation unknowns are resolved; remaining external inference/service/owner-installed behavior is explicitly unverified.
