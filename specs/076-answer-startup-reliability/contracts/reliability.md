# S076 interface contracts

Answer-synthesis providers receive a full typed schema and the existing bounded source context. Local native Ollama receives the same schema as format. Strict runtime shape and citation authority validation remain the acceptance boundary. Optional repair detail contains only generated schema metadata; arbitrary rejected output is never recycled as instructions.

Cold startup of an unsupported catalog schema produces code incompatible_version, reason catalog_schema_incompatible and exit 3. Recovery guidance selects a compatible executable or verified pre-upgrade backup. Explicit maintenance produces the same classification. Unknown initialization failures retain unavailable/runtime_catalog. No new startup transport fields are required.

Public envelope compatibility and historical documents remain separate from the narrower generation contract. Existing local/hosted adapter routes, bounds, cancellation and immutable history remain unchanged.
