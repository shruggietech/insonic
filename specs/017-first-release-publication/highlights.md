# insonic 1.0.0

insonic 1.0.0 brings a shared audio catalog and processing runtime to CLI and desktop packages for Windows x86-64, Linux x86-64 and macOS ARM64.

- Import recordings with preserved source metadata, canonical audio and timed Cueson transcripts.
- Configure local or connected processing, acquire exact model bundles, manage speakers and retrieve versioned speaker models.
- Explore source-linked evidence, timelines and saved graph queries, with optional query assistance.
- Create portable backups and restore catalog authority across configured storage, catalog and graph backends.

Downloads include offline documentation, integrity manifests, notices and complete corresponding sources. Packages have no configured publisher signatures or notarization. Automated qualification covers runtime and package behavior; acoustic accuracy has not been measured.
