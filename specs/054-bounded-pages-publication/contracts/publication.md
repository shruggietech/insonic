# Maintainer publication contract

Existing pages-promote arguments/results and release authority are retained. Internal GitHub.call gains an optional bounded timeout keyword. Pages staging passes the decreasing remaining allowance to every request.

Tree POST bodies are at most 1,048,576 encoded bytes, including base_tree and JSON escaping. Individually uploaded accepted files are at most 16,777,216 raw bytes and 25,165,824 request bytes. Returned blob identities and final tree entries must match original data. The first tree omits base_tree; subsequent batches extend only previous unpublished trees.

After exact inventory verification, the existing sole-parent commit, non-forced ref update/reconciliation, exact completed build, and maintained public verification remain required. Error context is bounded and credential-free for JSON requests and raw release uploads. A missing GET resource retains the client's existing None behavior; failed mutations, including 404, are errors.

Serial POST/PATCH operations are at least one second apart. Pacing and serialization consume the same original enclosing deadline; expiration during pacing prevents the next mutation.
