# Validation guide

1. Run focused Go parser, library, acquisition and playback regressions with prepared native companions and a hidden Windows launcher.
2. Run the existing installed-package CLI qualification in disposable libraries under a path containing spaces and Unicode. Inspect held leases, canonical MIME/bytes, embedded subtitle formats, transcript batches and loopback acquisition failures.
3. Release/expire old-report leases, restart the runtime and reconcile work. Current revision stays fixed after acceptance; obsolete report cleanup completes.
4. Inspect human/JSON wait/show/results and restart readback for deadline/byte-limit failures; prior accepted transcript remains intact and no private response/credential content appears.
5. Run npm run check, npm test, Go tests/vet, Python tests and affected docs/site/package checks. Read hosted Windows/Linux/backend qualification and final source identity before handoff.

No inference/model download or attended owner check is required. Verification evidence distinguishes executed local/hosted fixtures and unexecuted real inference, external providers and GUI interaction.
