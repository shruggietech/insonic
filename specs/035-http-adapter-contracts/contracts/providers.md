# Provider and error contracts: S035

## Extraction

Both insonic-http and legacy http select the same explicit contract-1 HTTP extraction path. Normalize before work/configuration provenance. Defaults remain cue-statement. Unknown or malformed provider fields, foreign/other-chunk cue IDs and clock-spoof fields cannot publish invalid assertions. Valid assertions retain authoritative source intervals and document/revision fences.

## Failures

Generic HTTP assistance reports fixed reasons for authentication, absent route/model, retryable provider failure, refused redirect, unavailable transport, invalid provider output and provider deadline. Existing compatible Ollama reasons remain; a provider deadline is distinct from parent cancellation. Redact raw provider bodies/headers, endpoint details and credentials. Both headers and streamed bodies are covered.

## Bounds

The generic category message must not claim every limit concerns child stdout. Existing result/HTTP/IPC ceilings and redirect/routing rules do not expand.
