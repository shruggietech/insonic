# v1.0.1

v1.0.1 adds optional, resumable setup and managed local processing environments and model readiness shared by the CLI and desktop. Windows gains an unsigned per-user MSI with selectable clients, alongside four Windows/Linux CLI and desktop archives.

CLI improvements include contextual help, durable failure inspection, import presets and clearer processing workflows. Consumers must read machine results from response envelopes and named model `files`. macOS support is withdrawn for this version; historical v1.0.0 downloads remain available.

Documentation now follows stable current-version links, offers compact mobile navigation and includes matching offline help. Packages retain complete inventories, dependency sources/notices and checksums. Optional model downloads remain separate; package qualification does not establish acoustic accuracy.
