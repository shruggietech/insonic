# Maintainer launch contract

- Release dispatch selects exact revision, publication boolean, promotion boolean and explicit Pages/generic transport. Publication defaults off; promotion defaults off. All package variants and runtime checks precede a validated release-target candidate.
- Pages preflight reads existing destination metadata/policy. Promotion uses trusted-main verifier code and the original asset set of an exact published release, not a rebuild. Only the Pages promotion job holds contents/pages write authority. Generic deployment retains its confined explicitly named credentials and environment.
- Package journey adds archive/receipt/revision election, mutually exclusive with source CLI/media/Cueson selectors. Selected package inventory pins native CLI, all media/Cueson companions and fixed processing worker. External Python/model selections remain explicit. Temporary extraction is owned and removed after the runtime ends.
- Controlled mode declares its synthetic acoustic adapter. Real mode uses installed worker bytes and records engine/model/runtime identity without unsupported quality claims.
- Owner handoff records exact reviewed SHA/run/attempt, six package hashes, docs target, signing state, actual timings, package journey results, highlights and post-squash exact-main rebuild commands. No product publication is elected by implementation PR authorization.
