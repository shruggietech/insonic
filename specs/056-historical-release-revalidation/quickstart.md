# Qualification procedure

1. Verify Python, Node, root/site dependencies, Git and the complete original source/assets are ready; record preparation separately.
2. Run focused release/history/MSI/archive failure tests, then the full maintained Python suite.
3. Run npm run check, npm test and affected site test/build through hidden noninteractive launchers.
4. Revalidate all original v1.0.1 assets against the complete pinned source using current tooling; retain compact original identities and results, without executing historical code/binaries.
5. Analyze/converge, push/open the PR, watch exact-head CI and audit terminal timing/artifact/terminal receipts.
6. Resolve at most two Codex rounds and all security findings, then stop before merge for owner review. Remove temporary source/assets after durable compact evidence retention.
