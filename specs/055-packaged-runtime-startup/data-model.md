# Evidence model

No product schema or persisted library changes.

A failed-terminal receipt binds format/platform/executable SHA-256, startup/workspace/runtime session/work/request UUIDs, owner and client PID/observed exit (unknown remains null), generated client mode and generated events. Native records require the matching client PID, one of stdout_pipe/stdin_pipe/command_start, known platform, Boolean errno availability and bounded unsigned numeric errno. Unknown fields and private text never survive selection.

Capture occurs before owned resources unwind. One bounded failure record per campaign is retained in the existing elected CI artifact directory; it is evidence of failure and cannot be accepted as a completed eight-case receipt. Missing or rejected observations are explicit statuses. Cleanup failure cannot replace the primary failure.
