# Qualification and candidate data model

## Journey receipt

Full code revision/dirty status, executable/worker/fixture digests, elected mode, operation transitions and accepted recording/audio/transcript/dataset/model/roster/query comparisons before and after restoration. Actual acoustic execution is distinct from deterministic adapter results. Absolute model/tool/workspace paths stay in ignored local configuration.

## Acoustic measurement

Exact engine/model identities, CPU/device/thread settings, duration/wall/output bounds, measured wall/CPU/RSS and generated recognition/diarization/enrollment/matching diagnostics. No diarization error rate without verified boundaries or independent identification accuracy from self/cross-clip consistency. Profile enrollment is not base-weight training.

## Release candidate

Reuse existing native-package/release-candidate contracts. Version 1.0.0 and one full clean source SHA bind six platform/variant keys, complete source inventories, public/offline documentation, final hashes/sizes and signing disposition. Missing, duplicate, corrupt or different-version/source-recipe inputs reject collection.

## Preparation state

Documentation status is candidate until publication. Current bindings advance while earlier schemas/docs remain immutable. Passing checks or a prepared version cannot establish product publication.
