# S019 operator contract

All commands accept --verbose, --debug, --quiet, --log-level error|warn|info|debug and --log-file FILE as global options. Scalar options occur once. Quiet conflicts with verbose/debug. Help admission has no file or workspace effects. JSON output remains one current runtime-response, existing stream/exit mapping and exact integer tokens.

Human rendering names actual selected operation/state, bounded readable fields and supported next commands. Quiet preserves warnings/errors and machine results. Only human terminal work wait emits transient changed state/stage/count observations; redirected waits emit only final/last output. Wait timeout stops waiting, not work.

Logs are opt-in private UTF-8 JSON lines with fixed generated fields. No stdin, credential values, filenames, URLs, prompts, documents, arbitrary provider/child text or payloads at any level. Each log is at most 1 MiB with two rotated predecessors.

Startup reports use internal runtime serve --startup-id UUID with protected stdin when needed; stdout is a bounded generated protocol, stderr is null. Parent validates exact correlation/version/workspace; successful detached lifetime does not depend on parent.

Inspection retains model incompatibility without electing execution. Materialized roles come from immutable manifests; each file retains publication/path/lease. Dataset readiness means preparation admission, not guaranteed usable acoustic examples.
