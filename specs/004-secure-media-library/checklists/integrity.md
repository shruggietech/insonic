# S004 integrity requirement checklist

- [x] Credential bootstrap precedes authenticated catalog open and never returns values.
- [x] All native backends prohibit prompts; vault has fixed reviewed crypto and atomic ownership.
- [x] Exact model manifests and all-file verification precede available status.
- [x] Stable source identity binds capture to admitted bytes.
- [x] Extraction partial/error/empty states and date uncertainty never masquerade as full capture.
- [x] Duration nullability and exact integer mapping distinguish unknown and zero.
- [x] Claims/retry/cancel and cleanup have explicit durable ownership contracts.
- [x] Current replacement removes old managed reports without deleting original inputs.
- [x] Historical migrations and both catalog/storage alternatives have blocking acceptance coverage.

These mark requirements completeness, not implementation completion.
