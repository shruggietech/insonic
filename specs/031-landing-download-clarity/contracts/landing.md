# Landing UI contract

All navigation/file actions remain native anchors. The hero `Choose a download` targets `#downloads` and is the only filled primary action. Windows MSI describes selectable Desktop/CLI/both with both default; separate ZIP alternatives and Linux tar.gz variants name OS, client and format. Guidance names its platform and exact content promise. Governed spacing, focus and target tokens apply.

The maintainer renderer takes explicit version/status/brand inputs and uses the same source component as Home. Browser fixture reports identify their state. Native activation probes intercept only navigation at test time and record exact destinations; they never follow external download URLs. Existing external HTTP/WebSocket blocks remain active.

Full-page screenshot and measurement cases cover 320/390/768/1440 CSS pixels in both themes, 200% real text enlargement and 320px reflow equivalent to 400% from 1280px. Screen-reader and other browser-engine certification are outside the automated proof.
