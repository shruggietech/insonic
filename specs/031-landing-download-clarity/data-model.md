# Data model: S031

- Package choice: version, platform, architecture, client variant, format, href and installation purpose. All five hrefs derive from existing `releaseDownloads`; no new product state.
- Landing link: accessible/visible label, raw href, resolved href, intent/category and current version. Include skip/home/header, hero, capabilities, architecture/archives, package/guidance and footer.
- Verification case: real export or explicitly released fixture, theme, CSS width, text scale, measured target/label boxes, focus/input result, image and elapsed time. A fixture is never a deployment receipt.
- Publication state remains specification/candidate/released under the existing manifest election. Unpublished states never emit package URLs.
