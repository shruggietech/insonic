# S010 admission contracts

Retain `media import` grammar and `--subtitle` compatibility; add `--transcript` alias, explicit transcript derivation/format and embedded index/language selectors. Standalone `transcript import SOURCE --record ID_OR_UNAMBIGUOUS_TITLE` uses the same admission service. `--replace-transcript` is its own election; no generic force permission.

Manifest source/transcript references resolve local paths relative to the manifest; URLs remain URLs. Independent transcript credential/budget fields never inherit media authentication accidentally. Per-item values override batch defaults.

Derivation modes: auto preserves supplied assignments, otherwise structured native participation; native follows the same non-clobber rules with diagnostics; off preserves supplied assignments/native facts without new derivation; diarize explicitly elects configured processing with supplied text and no recognition.

Results identify work/recording IDs, imported/replaced/skipped/failed outcome, document/source identity, selected/unused embedded tracks and bounded diagnostics. Expected skips succeed. Mixed batch failures remain visible without hiding accepted items.

Grouped audio is one .mka/FLAC authority with selected-track playback/preparation. Native scalar FLAC or mono MP3 follows approved policy. Tools, URL inputs and provisional candidates never establish accepted current state until fenced publication.

Existing transcript replacement checks accepted legacy sidecars as well as current Cue JSON. A successful conversion retires redundant managed native assets after reference/lease checks; never delete owner-owned paths.
