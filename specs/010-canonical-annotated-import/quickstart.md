# S010 validation guide

1. Run `npm run check`, `npm test`, `go test ./...` and `go vet ./...` through a hidden launcher on Windows.
2. Run frontend check/test/build and site build using existing package scripts.
3. Configure pinned media/Cueson tools and a disposable workspace.
4. Import committed bounded audio/video with explicit local, remote and embedded transcripts. Verify exact assignments/integers, selected tracks and one canonical audio/current document.
5. Import a standalone transcript against that stable recording. Verify default skip and explicit replacement, current-reference invalidation and failure/retry preservation.
6. Run grouped stereo/surround/offset fixtures and credential/redirect/bounds fixtures across affected native/backend qualification.
7. Verify final commit checks and all external review threads before the owner merge handoff. Real model execution is not required CI.
