# Contract entities

## Command guidance

Canonical paths and aliases have purpose, workspace scope, operands/options, units/defaults/conditions/exclusions/repeatability, workflow and executable tokens. Reviewed inventory equals accepted registry coverage. Substitutions are documented current identities, revisions, paths and fixture selections.

## Generated failure

Existing category/exit mapping remains. Stable causes identify syntax, duplicate/unknown keys, extra document, shape/type/enum/range/version and local/output prerequisites. Messages use known contract fields/constraints, never private values or arbitrary external output.

## Job duration

Exactly 1 <= duration_ms <= 600000. Schema 10 preserves job/attempt IDs, generations, timestamps, receipts and foreign keys. Schema-9 snapshots remain restorable. Boundary fixtures cancel immediately.

## Identity text

Public character limits count valid Unicode code points without normalization. Protected/document/transport byte ceilings remain independent. Model name/version bytes remain exact; quoted escaped identity display makes blank/multiline text visible.

## Observed result and human page

No established result means absent result on failure. Legitimate partial/false/zero observations remain. Summaries prioritize identities/revisions/digests, states, all task conclusions/corrections and continuation. Capture authority retains section, revision/digest and byte offsets; human decoding never changes JSON bytes.
