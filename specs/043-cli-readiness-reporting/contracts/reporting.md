# Reporting contracts

## Integrity and asset failures

Known managed-object or declared output size/hash failures use checksum_mismatch with generated reasons. Missing catalog selections and genuinely stale revisions retain their existing meanings. Wrong expected trainer bytes fail before publication admission.

Error.asset carries only role/name, reconstructed by SafeError from validated logical metadata. Fixed reasons distinguish missing, unreadable, not-regular, wrong-size, wrong-hash and missing-tool conditions. Human, JSON and durable work causes identify the same logical file and correction. No raw OS/provider/tool text, owner paths, command arguments or protected bytes are copied.

## Readiness and budgets

Offline download_bytes=0. Required, verified and missing local bytes are separately reported; nominal profile_download_bytes does not claim network activity. Unobserved local verification remains explicit.

Credential states distinguish absent/locked/unresolvable from locally resolvable; upstream authorization remains not_checked without network calls. Verified installed/local reuse bypasses unnecessary credential requirements. Pinned trainer files are inspected without invocation; protocol execution and model quality remain unverified. Training-only pipelines use training prerequisites rather than unelected recognition/diarization tasks.

## Wait

The elected wait budget covers readiness plus polling. Caller expiry returns wait_timeout with neutral inspection/continuation advice; explicit cancellation retains its existing category. Specific independently observed startup failure remains distinguishable. The last observed work response is retained, and absent observations remain unknown.
