# Validation guide

1. Run the focused contracts, artifact/filesystem/mock-S3, workers/models, trainer, app-readiness and work-wait tests through the verified hidden launcher.
2. Run npm run check, npm test, affected frontend/site checks and affected Python qualification tests. Test outputs use disposable owned directories and are removed.
3. Execute the existing source/extracted-package CLI qualification against tiny synthetic assets, protected dummy references and deterministic local/loopback trainers. Check human/JSON/durable outcomes and cleanup, never real owner profiles or credentials.
4. Push the exact checked source and publish the ordinary PR. Watch complete elected CI and initial automatic reviews. Resolve every actual finding, with at most one explicit second-round review request.
5. Converge against spec/plan/tasks and hand off the unmerged green PR. Report exact source/check/review identities and any unverified installed-release behavior; publish no release.
