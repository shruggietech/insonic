# Research decisions (2026-10-21)

- Error metadata: existing Diagnostic is subtitle-specific and SafeError currently rebuilds only Code/Reason. Use a small dedicated asset observation and generated reasons, extend the strict response schema, and reconstruct it at durable/output boundaries. Reject copying arbitrary cause strings or owner path basenames.
- Trainer integrity: publishOutput currently discovers a false path-backed hash after artifact admission and retirement. Check Stage's stable scratch digest/size before BeginPublication through PublishVerified; preserve existing upload readback, idempotence, catalog fences and reconciliation. A separate prehash/reopen would add I/O and a race.
- Physical objects: Verify, filesystem/S3 range responses and MaterializeBound conflate mismatch with revision conflict. Distinguish recognized physical absence/mismatch locally; do not globalize not_found or alter authorization/storage outages.
- Asset verification: worker runtime/installer/wheel and model local-role checks already exist. Reuse them for budget observations and failures; avoid a second hash policy. Inspect declared names only, ignoring unrelated directory content.
- Credential preview: Status may reflect an index/envelope without usable bytes. Resolve locally required references once with cancellation support, clear returned bytes and retain unknown upstream authorization; no HTTP probe. Verified reuse requires no new credential.
- Training readiness: custom adapters are always configured_not_probed, and pipeline usability currently requires recognition plus diarization. Reuse actual pinned executable/support validation and assess elected tasks; file verification is not runtime protocol or acoustic-quality proof.
- Wait: Ensure currently receives the caller budget but its failure bypasses waitForWork's timeout normalization. Normalize at the CLI wait boundary; keep generic Ensure and its independent startup deadline unchanged.
- Qualification: cli_contract_qualification.parallel_regressions already owns isolated libraries/hidden ProcessTree children; documented_workflows already supplies deterministic current datasets and loopback trainers. Extend these, with no new campaign or retained build journals.
