# S049 Research Decisions (2026-10-25)

- Decision: Canonicalize and validate the actual temporary parent; reject empty, relative, volume/share-root and root-alias inputs. Rationale: both Windows consumers explicitly discarded the valid temp path. Alternative rejected: shortening paths by allocating at a drive root, because no measured path-length necessity justifies it.
- Decision: Share a small allocator retaining parent and fixture device/inode identities before initialization; commit an ownership marker only after its write succeeds. Rationale: failed/partial marker initialization must not strand a known owned directory. Refuse recursive removal on unknown/replaced identity and report the exact residual and cause. Alternatives rejected: prefix-only deletion and arbitrary old-directory sweeps.
- Decision: Preserve child-release ordering, retain/close the persistent context itself, settle browser launch before fixture removal and report child-release failures. Rationale: Promise.race deadlines do not cancel operations and context.browser() can be absent.
- Decision: Keep detailed fixture locations in qualification diagnostics; public capture receipts get non-private parent policy/basename/removal metadata. Include the shared helper in capture source hashing.
- Decision: Enable actual application capture on Linux as well as Windows, platform-qualify artifact names, and add Windows documentation UI to the desktop lane using existing verified exports and browser discovery. Existing Linux documentation UI remains authoritative. Rationale: current CI covers only Windows app and Linux docs. Linux application environment needs fixed system utility paths without owner PATH/secrets.
- Audit: live-site UI uses actual os.tmpdir(); density capture uses ignored buildRoot; renderer uses Python TemporaryDirectory. Neither repeats the root-extraction defect. Existing test fixtures also use actual temp parents. No unrelated cleanup or framework migration is warranted.

Spec Kit Phase 0 used two read-only research agents for lifecycle/ownership and platform qualification. All implementation unknowns are resolved; pre/post-design constitution gates pass.
