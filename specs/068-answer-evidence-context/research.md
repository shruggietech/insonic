# S068 Research (2026-11-01)

Spec Kit plan research agents reviewed retrieval/catalog/graph integration and context/artifact persistence. Read-only research completed; all design unknowns resolved.

1. Decision: add bounded catalog cue projection and typed graph neighborhood pages. Existing runQuery -> publishGraph -> Catalog.Export/explore.Build and ReadRefs hydrate the whole library; repeating that path would violate the request budget. Reuse normalized filters and authority, not whole-snapshot logic. Candidate rows, bytes, edges, rounds and elapsed time are charged before filtering.
2. Decision: use general cue references with recording/document/source/map/mapping/date identity; speaker-specific ResolveEvidence rejects unknown voices and is unsuitable. Project one cue at a time in a repeatable catalog read and use existing source-clock conversion.
3. Decision: use a thin, ordered source-identity epoch for continuation, under the same finite scan/byte/deadline allowance; report incomplete scope if identity inventory exceeds that allowance. Do not use global catalog revision as semantic cache authority. Immutable cache keys bind selected evidence plus scope/configuration; freshness is rechecked independently.
4. Decision: bounded graph reads do not publish or rebuild. Report graph lag/unavailability, retain direct catalog evidence, and validate every graph-derived source against current catalog authority. Both edge endpoints must belong to the selected workspace; page continuation pins graph checkpoint identity.
5. Decision: exact canonical source and accepted common-origin lineage establish source families. Text equality does not. Overlap and derived assertions cannot increase independent support. Contradiction detection is limited to explicit matching assertion propositions with opposite polarity; unsupported semantic inference is not claimed.
6. Decision: deterministic extractive context with cue/section/recording/cross-recording hierarchy. Charge the entire serialized provider context, including links, using explicit conservative UTF-8-byte token accounting; disclose this accounting rather than claiming an exact provider tokenizer. Never paraphrase source claims in this slice.
7. Decision: artifact-backed immutable JSON packages and content-addressed NamedSetting pointer indexes reuse filesystem/S3 and SQLite/PostgreSQL snapshot authority without a catalog migration. Retain artifacts before pointer admission, reconcile unknown CAS outcomes by exact readback, and replace corrupt cache pointers with new publications. Cache indexing must not dirty the source graph. Source fences are checked before/after publication and on inspect/export.
8. Decision: expose answers prepare/show/export/validate for evidence/context preparation and future answer-envelope validation. Existing #224/#225 retain synthesis and complete durable answer-generation workflows. No new tracking issue, release or owner merge. Published software/docs/schema version remains aligned at 1.1.0 until a separately prepared release.

Alternatives rejected: full-library query wrapping, text-only source deduplication, global-revision-only cache keys, authoritative plaintext cache sidecars, new persistence tables/migrations, and premature free-form answer synthesis.
