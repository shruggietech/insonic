# Dependency identities

- Dependency selection: context, exact direct version and required resolved closure. Root/site/Go contexts stay distinct; replacements remain the approved local directories.
- Upstream source identity: approved module/version, pristine h1 checksum, source manifest and patched tree hash. Missing or mismatching authority is rejected.
- Qualified candidate: clean source revision, run/attempt, verified archive/inventory identities, elected results and terminal timing. Required results cannot be replaced by parser accounting or cache warmth.
- Superseded update: original PR, requested version set and qualified replacement link. Pending -> represented -> qualified -> superseded; owner merge of the replacement remains separate.
