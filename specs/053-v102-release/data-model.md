- Candidate: canonical version1.0.2, exact reviewed source identity, unpublished state, synchronized software/docs/schema bindings, complete package/inventory/signing disposition.
- Historical authority: published version1.0.1, original source136f5c0307a6fce00ba8240ef69c907a944cd8c0, immutable tag/assets/schema identities, released navigation and original capture receipts.
- Capture: version1.0.2, clean source/version/inventory identity, image hashes and producer/attempt. Historical receipt versions cannot be rewritten. Final current pages require matching validated captures.
