# Desktop startup failure contract

1. A returned startup failure exits unsuccessfully and preserves its original cause and generated stage.
2. Ordinary GUI launches attempt visible native failure feedback even without a console or initialized browser. Explicit unattended qualification retains noninteractive output.
3. The application attempts a bounded private event under its per-user insonic/diagnostics configuration directory. Events include generated startup stage and optional numeric system error, never arbitrary native error text, local path details or protected input.
4. Feedback states whether private diagnostics were saved. Failure to create, secure, lock, write or close that log does not replace the original startup cause.
5. Windows diagnostic log/lock creation works in ordinary inherited-Modify directories. File ownership, identity, protected current-user DACL and reparse protections remain required, including existing files and rotation.
6. The recovery increment completes synchronous/asynchronous startup failures as failures, skips normal application-loop entry, cleans up owned partial initialization on its owning thread after callbacks unwind, and permits a later valid process using the intended profile.
7. No automatic retries, silent profile deletion, forced browser termination, new routing or GUI-framework replacement are introduced. Historical signatures are not asserted to share one cause.

8. Windows native/package acceptance requires startup_recovery=passed only after the controlled failed child, matching private event, normal child/owned-descendant release and subsequent valid same-profile launch. Its distinct failure-lifecycle and recovery receipts do not replace or inflate the twelve original native-exit lifecycle receipts.
9. Maintained source authority accepts exactly the pinned go-webview2 and Wails modules, their hardcoded patch scopes, complete file inventories and upstream/patched checksums. Preparation recipes bind both trees, and package notices verify each linked logical module and patch notice.
